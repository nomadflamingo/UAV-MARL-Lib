# Unmanned Aerial Vehicle Multi-Agent Reinforcement Learning Library
This Library builds of the PyFlyt UAV flight simulator with more additional multi-agent environments and example Reinforcement Learning strategies to compare new strategies to.

<p align="center">
    <img src="https://github.com/jjshoots/PyFlyt/blob/master/readme_assets/pyflyt_cover_photo.png?raw=true" width="600"/>
</p>

## Installation 
This repository does have a docker image however there are some issues when using the Gymnasium GUI.
